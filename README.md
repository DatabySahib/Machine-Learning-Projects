# Machine Learning Projects

Bu qovluqda maşın öyrənməsi (Machine Learning) və dərin öyrənmə (Deep Learning) sahələrində həyata keçirdiyim müxtəlif təcrübə və layihələr toplanıb. Hər bir layihə ayrıca Jupyter Notebook (`.ipynb`) faylı şəklində təqdim olunub və məlumatın təhlilindən modelin qurulmasına qədər bütün mərhələləri əhatə edir.

## 📂 Layihələr

| Notebook | Mövzu |
|---|---|
| `Breast_cancer_detection.ipynb` | Xərçəng diaqnostikası üçün klinik göstəricilər əsasında xoş/bədxassəli şişin təsnifatı |
| `Clustering_Antarctic_penguin_species.ipynb` | Nəzarətsiz öyrənmə ilə Antarktida pinqvin növlərinin klasterləşdirilməsi |
| `Facial_recognition_with_supervised_learning.ipynb` | Nəzarətli öyrənmə ilə üz tanıma (LFW dataset əsasında) |
| `Predict_credit_card_approvals.ipynb` | Kredit kartı müraciətlərinin təsdiqlənib-təsdiqlənməyəcəyinin proqnozlaşdırılması |
| `Predict_energy_consumption.ipynb` | Enerji istehlakının proqnozlaşdırılması |
| `Predict_insurance_charges.ipynb` | Sığorta xərclərinin reqressiya modelləri ilə proqnozlaşdırılması |
| `Predictive_modeling_for_agriculture.ipynb` | Torpaq göstəriciləri əsasında əkin üçün ən uyğun bitkinin proqnozlaşdırılması |
| `Reveal_categories_found_in_data.ipynb` | Klasterləşdirmə vasitəsilə məlumatda gizli kateqoriyaların aşkarlanması |
| `Service_desk_ticket_classification_with_deep_learning.ipynb` | Dərin öyrənmə ilə IT dəstək müraciətlərinin (ticket) təsnifatı |
| `Speech_emotion_recognition_with_librosa.ipynb` | Librosa kitabxanası ilə səsdən emosiyanın tanınması |
| `What_makes_a_good_book.ipynb` | Kitab reytinqlərinə təsir edən amillərin təhlili |
| `Wine_quality_prediction.ipynb` | Fiziki-kimyəvi göstəricilər əsasında şərabın keyfiyyətinin proqnozlaşdırılması |
| `Word_frequency_in_Moby_Dick.ipynb` | "Moby Dick" romanının mətn təhlili və söz tezliyinin hesablanması (NLP) |

## 🛠️ İstifadə olunan texnologiyalar

- **Python** — əsas proqramlaşdırma dili
- **Pandas, NumPy** — məlumatların emalı və analizi
- **Matplotlib, Seaborn** — vizuallaşdırma
- **Scikit-learn** — klassik ML modelləri (reqressiya, təsnifat, klasterləşdirmə)
- **Librosa** — audio siqnalların emalı
- **Deep Learning** kitabxanaları — mətn və ticket təsnifatı üçün

## 📁 Struktur

```
Machine Learning Projects/
├── *.ipynb              # Hər layihə üçün ayrıca notebook
└── data/                 # Layihələrdə istifadə olunan dataset-lər (.zip formatında)
```

## 🚀 İstifadə qaydası

1. Repozitoriyanı klonlayın:
   ```bash
   git clone https://github.com/DatabySahib/Machine-Learning-Projects.git
   ```
2. `Machine Learning Projects` qovluğuna keçin.
3. İstədiyiniz `.ipynb` faylını Jupyter Notebook, Google Colab və ya VS Code-da açın.
4. `data/` qovluğundakı müvafiq arxivi çıxarıb (unzip) notebook-un istifadə etdiyi yola uyğun yerləşdirin.
5. Kod xanalarını ardıcıl işə salın.

## 📌 Qeyd

Layihələr öyrənmə və təcrübə məqsədi daşıyır və müxtəlif ML/DL üsullarını (nəzarətli öyrənmə, nəzarətsiz öyrənmə, NLP, audio emalı və s.) praktik nümunələr üzərində göstərir.
